# ADR-034 — No Phase Gates: كل الوحدات المشحونة لايف، والوصول RBAC فقط

التاريخ: 2026-10-29 · الحالة: مقبول ومنفّذ

## القرار

1. **لا مفهوم «مرحلة» في المنتج.** الوثائق والأقساط والإصدار والتقارير والتصدير وحدات
   مشحونة وكانت تُحرس بعلم قاعدة بيانات `phase2.enabled` يردّ `503 feature_disabled`
   وبواجهة «غير مفعّلة بعد / تشغيل هذه المرحلة (تجربة)». أُزيلت الحراسة من الكود
   التشغيلي بالكامل: لا شرط علم في أي مسار، ولا مكوّن بوابة في أي شاشة.
2. **الصلاحية هي الحارس الوحيد**: `policies.view` / `policies.manage` /
   `reports.view` / `reports.export` / `commissions.view` … وما عداها يردّ
   403 (صلاحية) أو 404 (خارج النطاق) — أبدًا 503 بسبب علم.
3. **التوافق الخلفي**: جدول `feature_flags` والمسار العام `GET/PATCH /feature-flags`
   يبقيان (تستخدمهما أعلام أخرى مثل `ai.enabled` — مفتاح مزوّد خدمة، لا بوابة
   وحدة مشحونة)، وصف `phase2.enabled` إن وُجد في قاعدة قائمة يبقى بلا قارئ؛
   البذرة الجديدة تزرعه `enabled=true` لأي قاعدة جديدة حتى لا يقرأه إنسان كإشارة
   إطفاء. لا migration جديدة (لا تغيير مخطط).
4. يبقى `FeatureDisabled` (503) لعلم `ai.enabled` فقط — تعطيل مزوّد ذكاء اصطناعي
   خارجي قرار تشغيلي للمزوّد، ولا يخفي أي شاشة مشحونة: شاشات المكالمات/الطلبات
   تعمل، وزر التلخيص وحده يردّ بأن المزوّد معطّل.
5. أسماء داخلية تاريخية (`app/models/phase2.py`، مجلد `features/phase2/`،
   مساحة أسماء i18n ‏`phase2.*` للنصوص التشغيلية مثل «الوثائق والأقساط») ليست
   واجهة مستخدم ولا تُعاد تسميتها: إعادة التسمية مخاطرة استيراد بلا قيمة منتج.
   ما رآه المستخدم من لغة المراحل («مرحلة ثانية»، «غير مفعّلة بعد»، «تجربة»)
   حُذف نصيًا من ar/en.

## لماذا

الوحدات مبنية ومختبَرة منذ جولات؛ إبقاؤها خلف علم يجعل منتج الـpilot يبدو ناقصًا
ويضيف شرطًا تشغيليًا لا يحرس شيئًا لا تحرسه الصلاحيات أصلًا. الحارس الصحيح
لبيانات مالية هو RBAC + النطاق + التدقيق، وكلها قائمة ومختبَرة.

## العواقب

- الاختبارات التي كانت تتوقع 503 عند إطفاء العلم أُعيدت كتابتها لتوقّع السلوك
  الطبيعي: 200 بالصلاحية، 403 بدونها — لم يُخفَّف أي اختبار؛ تغيّر المتوقَّع
  لأنه تعريف المنتج الجديد.
- مساعدو `_enable_phase2` في اختبارات قديمة بقوا بلا ضرر (يكتبون صف علم لا
  يقرأه أحد) وسيُزالون في تنظيف لاحق؛ الاختبارات الحاكمة للسلوك الجديد
  موجودة في `test_no_phase_gates.py`.
